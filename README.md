# Sales Data Analysis Using Python and Power BI

## Project Overview

This project focuses on analyzing sales data to understand business performance, identify sales trends, and evaluate profitability across different product categories and regions. The analysis helps convert raw data into meaningful business insights for better decision-making.

## Objectives

- Analyze overall sales and profit performance.
- Identify monthly sales trends.
- Compare sales across product categories and sub-categories.
- Understand payment mode preferences.
- Build an interactive dashboard to visualize key business metrics.

## Tools and Technologies

- **Python:** Data analysis and data cleaning
- **Pandas:** Data manipulation and preprocessing
- **NumPy:** Numerical operations
- **Power BI:** Interactive dashboard and data visualization
- **CSV:** Dataset storage and data exchange

## Project Workflow

1. **Data Loading:** Imported the sales dataset for analysis.
2. **Data Cleaning:** Checked for duplicate records and reviewed data quality.
3. **Data Analysis:** Examined sales, profit, product categories, payment modes, and monthly trends.
4. **KPI Analysis:** Evaluated total sales, total profit, and profit margin.
5. **Data Visualization:** Created charts and interactive visuals in Power BI.
6. **Insights:** Used the analysis to understand business performance and identify important trends.

## Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Profit Margin
- Category-wise Sales
- Monthly Sales Trends
- Payment Mode Distribution

## Key Insights

- Identified the month with the highest sales.
- Compared sales performance across product categories and sub-categories.
- Evaluated profitability using total profit and profit margin.
- Explored payment mode preferences to understand customer purchasing behavior.
